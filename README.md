Tactical Breach — a round-based tactical FPS: bot AI with routes and shooting, bomb plant/defuse objective, buy menu with a carry-over economy, 3 weapons (rifle, pistol, knife) + HE grenade, procedural WebAudio sound effects, built on three.js 0.187.0.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
